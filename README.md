# Ryko AI — طبقة الثقة للوكلاء 🛡️
**Agent Trust Layer (Arabic-first)**

> المراقبة تخبرك ماذا قال وكيلك. **Ryko يخبرك هل فعل ما قال.**

بوابة واحدة يمر عبرها كل استدعاء وأداة لأي وكيل (مهما كان إطاره):
تسجّل كل شيء بسجل غير قابل للتلاعب، تدقّق الادعاءات مقابل الأثر الفعلي،
تحكم الصلاحيات، وتقيس صافي الجدوى الاقتصادية.

## الأنوية الأربع
| النواة | الوظيفة | الحالة |
|---|---|---|
| 📦 المسجّل Recorder | سجل JSONL متسلسل الهاش (Hash-Chain) | بذرة عاملة ✅ |
| 🔍 المدقّق Auditor | كشف الهلوسة الإجرائية PHR (ادعاء بلا أثر) | بذرة عاملة ✅ |
| 🚦 الحاكم Governor | صلاحيات R0–R3 + بوابة بشرية | قادم (G3) |
| 💰 الاقتصادي NAG | هل تستحق المهمة وكيلاً أصلاً؟ | قادم (G4) |

## جرّب الآن
```bash
python demo.py
```
سيرى السجل ادعاءً كاذباً مزروعاً («شغّلتُ الاختبارات ونجحت» بلا أثر) ويكشفه.

## خارطة الطريق (بوابات قبول)
G1 تسجيل كامل ← G2 تدقيق ≥90% ← G3 صفر فعل R3 بلا موافقة ← G4 مختبر AUL.
التفاصيل في [SPEC.md](SPEC.md).

جزء من منظومة TibaTech العربية-first (zyko · ضاد · MIZAN · model-council).
الرخصة: Apache-2.0 (نواة مفتوحة، وحدات امتثال مؤسسية لاحقاً).
